# Mega Lopunny ex — デッキの勝ちパターンと操縦ルール

エージェント: [`agents/lopunny/main.py`](../agents/lopunny/main.py)
デッキ: Majkel1337(8/1時点 Elo #4、623戦 WR63%)の60枚リスト

## なぜこのデッキか (2026-08-01 メタ分析, 4,516戦)

| アーキタイプ | トップ層シェア | 勝率 |
|---|---|---|
| Marnie's Grimmsnarl ex | 39.0% | 52.2% |
| **Teal Mask Ogerpon ex** | 23.6% | 58.2% |
| **Mega Lopunny ex** | 21.9% | **61.2%** |
| Mega Kangaskhan ex | 8.9% | 53.4% |
| Alakazam | 4.1% | 62.0% (n=137、母数小) |

ミミロップはトップ層で最高勝率かつ**7/30時点ではシェア0.2%** — 2日で急拡大した新興デッキ。
ルールベースで操縦しやすい単純なループを持つ点が、当プロジェクトの方針(強いパターンの
押し付け)と合致する。

## コアループ: 1エネで毎ターン230ダメージ

**Gale Thrust (エネルギー1個) = 60。ただし「このターンにベンチ→バトル場に移動した」なら +170 = 230。**

条件はにげる(retreat)で毎ターン満たせる:

1. ベンチのミミロップにエネルギー1個を付けておく
2. バトル場のポケモンをにげる — **かるいし(Air Balloon)でにげるコスト0**
3. 準備済みミミロップがベンチから登場 → 条件成立 → **230ダメージ**

かるいしが必須なのは、通常のにげるは**にげるコスト分のエネルギーを捨てる**ため。
ミミロップの1個しかないエネルギーを捨てるとアタッカーでなくなる。

耐久は HP330 + **ワリィのやさしさ(全回復 + 付いていたエネルギーを手札に戻す)** 4枚。
デッキのエネルギーが8枚しかないのはこの回収があるため。

## リプレイ分析で判明した操縦ルール

Majkel1337 の実戦40〜60戦を自エージェントでリプレイし、選択の不一致を
カード名にデコードして導出([`tools/divergence.py`](../tools/divergence.py),
[`tools/ctx_probe.py`](../tools/ctx_probe.py))。

### 1. 先攻を取る (IS_FIRST: 14/14)
攻撃開始より、ミミロップ2体分の準備を先に完了させる方が強い。

### 2. 倒された後の補充(TO_ACTIVE)と、にげる先(SWITCH)は正反対
これが最大の発見。**同じ「ベンチから前に出す」でも意味が逆**:

- **SWITCH(自分のターンのにげる先)** → **必ず準備済みミミロップ**。
  これが「このターン移動した」=+170 の条件を満たす主体だから。
- **TO_ACTIVE(倒された後の強制補充)** → **準備済み(エネルギー付き)ミミロップ**。
  ただし**エネルギーの付いていないミミロップは絶対に出さない**。

実測(182回の補充判断):

| 出したポケモン | 回数 | エネルギー有り |
|---|---|---|
| ノコッチ | 108 | 2回のみ |
| **Mega Lopunny ex** | 57 | **56回** |
| Fan Rotom / Buneary / Dudunsparce | 17 | — |

→ エネルギーの付いていないミミロップは前に出さない(57回中1回)。
攻撃できない3枚サイドの的を置くだけになるため。

### ⚠ 集計の落とし穴(一度間違えた)

上表だけを見て「原則ノコッチ(捨て駒)」と結論したが**これは誤り**だった。
この集計は「そもそも準備済みミミロップが選択肢に無かった場面」を含んでいる。
**両方が選択肢にあった場面だけに条件付ける**と、結論が逆転する:

| 相手アーキタイプ | ミミロップを出した | 捨て駒 | ミミロップ率 |
|---|---|---|---|
| Marnie's Grimmsnarl ex | 46 | 15 | 75% |
| Mega Kangaskhan ex | 45 | 15 | 75% |
| Teal Mask Ogerpon ex | 32 | 15 | 68% |
| **Mega Lopunny ex(ミラー)** | 97 | 92 | **51%** |

→ **ミラー以外では準備済みミミロップを出す**。HP330を相手が短期間で
突破できないため、捨て駒を出すのは毎ターンサイドを献上するだけになる。
ミラーだけは相手も230を撃ってくるので五分の判断になる。

教訓: 条件付けを間違えた集計は、正しく見える誤った結論を出す。
比較したい2択が**両方とも選べた場面**に絞ってから数えること。

### 3. ドローエンジンを毎ターン回す
ノコッチ(basic) → ノココッチ(進化)の特性 **Run Away Draw = 3枚引いて自身を山札に戻す**。
自分が山に戻るので何度でも再利用でき、パイロットは毎ターン使っている
(211〜316回/40戦)。ノコッチを場に出す行為も毎ターン(313回)。

### 4. 捨てるものの優先順位: 余ったエネルギー > サポート > アイテム
アタッカー1体につきエネルギーは1個で足り、ワリィのやさしさで回収もできるため、
手札に2枚以上ある特殊エネルギーが最も捨ててよい。サポートは1ターン1枚しか
使えず4枚積みなので2枚目以降は死に札。逆に**かるいしとミミロップは死守**
(かるいしはループの動力源)。

## ラダー65戦の解剖 — 何が実際に負けを生んでいたか

ローカルのガントレットは81.7%、実ラダーは42%。この乖離の原因を
[`tools/loss_profile.py`](../tools/loss_profile.py) と
[`tools/weak_attack_why.py`](../tools/weak_attack_why.py) で特定した。

|  | 勝ち試合 | 負け試合 |
|---|---|---|
| 自分のターン数 | 8.0 | 7.0 |
| 攻撃回数 | 6.5 | 5.0 |
| **うち230ダメージ** | **3.7** | **2.1** |
| 攻撃しなかったターン | 1.6 | 2.1 |

**Gale Thrust の48%が60ダメージ止まり**(230が179回、60が163回)。
デッキの前提が半分しか成立していなかった。理由の内訳:

| 割合 | 理由 |
|---|---|
| 63% | ベンチにミミロップが1体もいない(=ループを回す2体目が無い) |
| 22% | にげるのにエネルギーを捨てる必要があり、60で殴る方を選んでいた |
| 15% | ベンチにミミロップは居るがエネルギーが付いていない |

### 対策と効果

1. **2体目の確保を最優先に** — サーチ時、場のミミロップが2体未満なら
   ミミロップ/ブニャットをドローエンジンより上位に。またヒルダ(唯一
   ミミロップを確実に持ってこられる札。ポケパッドはex不可)を、
   2体目が無いときはリーリエのてぎわより優先。
2. **にげるコストを払ってでも230を撃つ** — エネルギー1個の損失より
   +170ダメージの方が価値が高い(スコア 3500 → 5500)。

**エンジン発動率(全Gale Thrustのうち230だった割合)**:

| | 発動率 |
|---|---|
| 修正前(実ラダー実測) | 52% |
| 修正前(ローカル実測) | 51.0% |
| 2体目確保の修正後 | 55.2% |
| **にげるコスト修正後** | **69.1%** |

この指標は勝率と違い**ローカルと実ラダーがほぼ一致した**(51% vs 52%)ため、
版の判定に使える数少ない信頼できる尺度。相手別: Grimmsnarl 69.1%、
Lucario 68.5%、Ogerpon 56.6%、Alakazam 28.4%(最も苦手な相手)。

## Alakazam戦(最悪の相性)の解剖 — 操縦では直らない

エンジン発動率28.4%・勝率28%と突出して悪かったため個別に調べた。

**相手の仕組み**: Powerful Hand は「手札1枚につきダメカンを2個置く」。
手札15枚なら300ダメージ。しかもこれは**ダメージではなく「効果」**であり、
こちらの**霧のエネルギーは「相手の技の効果を全て無効化」する** —
つまり完全に無力化できる札を4枚積んでいる。

実装して検証した結果:
- **仕組みは本物**。ログ上、霧が付いている間は Powerful Hand がダメカンを
  1個も置いていない。
- アクティブなミミロップに霧を載せられた割合は **42%**(デッキ比率どおり)。
- しかし **勝率は 28% → 30%(150戦)** でほぼ動かない。

**動かない理由はサイドの計算**にある。相手はアブラ/ユンゲラー/フーディンが
全て非exの**1枚サイド**。こちらの主力は Mega ex で**3枚サイド**。
つまり **相手は2回倒せば勝ち、こちらは6回倒す必要がある**。
攻撃を何度か無効化しても、3倍のサイド差は埋まらない。

実ラダーの相性データ(ミミロップ対Alakazam = 35%)とも一致しており、
**これはデッキ構造の問題であって操縦の問題ではない**というのが結論。
霧の優先付けは、この相手にしか発動しない安全な変更なので残してある。

## 実戦検証 — 確定版 (各120戦 / 相手、合計720戦)

**先に結論: v1 と v2 は差がない。** 下の40戦版で出た「v2が+4.4pt」は
ノイズだった(同一条件の再測定で Grimmsnarl 92%→82%、Ogerpon 70%→55% と振れた)。

| 相手 | シェア | v1 | v2(提出済み) |
|---|---|---|---|
| Marnie's Grimmsnarl ex | 39.0% | 88% | 85% |
| Teal Mask Ogerpon ex | 23.6% | 69% | 68% |
| Mega Lopunny ex (ミラー) | 21.9% | 92% | **98%** |
| Mega Kangaskhan ex | 8.9% | 82% | **88%** |
| Alakazam(本格パイロット) | 4.1% | 26% | 30% |
| Team Rocket's Mewtwo ex | 1.6% | 92% | **97%** |
| **重み付き勝率** | | **81.6%** | **81.7%** |

v2 はミラー・Kangaskhan・Mewtwo で明確に上回るが、シェア39%の Grimmsnarl で
3pt 下回るため、重み付けでは相殺される。**補充ルールの修正は理屈としては
正しかったが、勝率としては測定できる差を生まなかった。**

なお Alakazam 戦 26〜30% は、汎用ボットではなく本格パイロットを相手にした値。
実ラダーの相性データ(35%)とよく一致しており、ここだけは信頼できる。

## 却下した変更(記録)

トップパイロットの MAIN 選択回数を見ると PLAY:Dunsparce が最多だったため、
Dunsparce の優先度を攻撃ラインより上に引き上げた。結果は **86.3% → 79.8%**
(Grimmsnarl戦 92%→78%)で明確に悪化したため差し戻した。

教訓: 一致率(divergence)が示唆する変更でも、必ずガントレットの勝率で
検証してから採用すること。行動の**回数**は優先**順位**を意味しない
(相手が何度も打つ札は、単にその札の枚数が多いだけかもしれない)。
