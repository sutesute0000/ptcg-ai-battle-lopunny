# Mega Lopunny ex — デッキの勝ちパターンと操縦ルール

エージェント: [`agents/lopunny/main.py`](../agents/lopunny/main.py)
デッキ: Majkel1337(8/1時点 Elo #4、623戦 WR63%)の60枚リスト

| アーキタイプ | トップ層シェア | 勝率 |
|---|---|---|

ミミロップはトップ層で最高勝率かつ**7/30時点ではシェア0.2%** — 2日で急拡大した新興デッキ。
ルールベースで操縦しやすい単純なループを持つ点が、当プロジェクトの方針(強いパターンの
押し付け)と合致する。

## コアループ: 1エネで毎ターン230ダメージ

**Gale Thrust (エネルギー1個) = 60。ただし「このターンにベンチ→バトル場に移動した」なら +170 = 230。**

条件はにげる(retreat)で毎ターン満たせる:

1. ベンチのミミロップにエネルギー1個を付けておく
2. バトル場のポケモンをにげる — **かるいし(Air Balloon)でにげるコスト0**
3. 準備済みミミロップがベンチから登場 → 条件成立 → **230ダメージ**

かるいしが必須なのは、通常のにげるは**にげるコスト分のエネルギーを捨てる**ため。
ミミロップの1個しかないエネルギーを捨てるとアタッカーでなくなる。

耐久は HP330 + **ワリィのやさしさ(全回復 + 付いていたエネルギーを手札に戻す)** 4枚。
デッキのエネルギーが8枚しかないのはこの回収があるため。

## リプレイ分析で判明した操縦ルール

Majkel1337 の実戦40〜60戦を自エージェントでリプレイし、選択の不一致を
カード名にデコードして導出([`tools/divergence.py`](../tools/divergence.py),
[`tools/ctx_probe.py`](../tools/ctx_probe.py))。

### 1. 先攻を取る (IS_FIRST: 14/14)
攻撃開始より、ミミロップ2体分の準備を先に完了させる方が強い。

### 2. 倒された後の補充(TO_ACTIVE)と、にげる先(SWITCH)は正反対
これが最大の発見。**同じ「ベンチから前に出す」でも意味が逆**:

- **SWITCH(自分のターンのにげる先)** → **必ず準備済みミミロップ**。
  これが「このターン移動した」=+170 の条件を満たす主体だから。
- **TO_ACTIVE(倒された後の強制補充)** → **原則ノコッチ(捨て駒)**。
  相手ターンの終わりに出るので「このターン移動」にならず、次の自分のターンに
  ミミロップを出しても60しか出ない。捨て駒を挟めば、次ターンに
  「にげる→ミミロップ登場→230」が成立する。しかも倒されて渡すサイドが
  3枚(Mega ex)ではなく1枚で済む。

実測(182回の補充判断):

| 出したポケモン | 回数 | エネルギー有り |
|---|---|---|
| ノコッチ | 108 | 2回のみ |
| **Mega Lopunny ex** | 57 | **56回** |
| Fan Rotom / Buneary / Dudunsparce | 17 | — |

→ **エネルギーの付いていないミミロップは絶対に前に出さない**(57回中1回)。
準備済みミミロップを出すのは、ベンチにもう1体準備済みが残っていて
ループを継続できるときだけ。

### 3. ドローエンジンを毎ターン回す
ノコッチ(basic) → ノココッチ(進化)の特性 **Run Away Draw = 3枚引いて自身を山札に戻す**。
自分が山に戻るので何度でも再利用でき、パイロットは毎ターン使っている
(211〜316回/40戦)。ノコッチを場に出す行為も毎ターン(313回)。

### 4. 捨てるものの優先順位: 余ったエネルギー > サポート > アイテム
アタッカー1体につきエネルギーは1個で足り、ワリィのやさしさで回収もできるため、
手札に2枚以上ある特殊エネルギーが最も捨ててよい。サポートは1ターン1枚しか
使えず4枚積みなので2枚目以降は死に札。逆に**かるいしとミミロップは死守**
(かるいしはループの動力源)。

## 弱点

- **全ポケモンが格闘弱点**({F})。Cynthia's Garchomp ex 相手は相性表で10%。
  ただしメタ上の母数は小さく、パイロットは割り切っている。
- シェア39%の Grimmsnarl 相手は 53% と拮抗 — ここが改善の主戦場。

## 適用結果(トップパイロットとの一致率)

| 判断コンテキスト | 修正前 | 修正後 |
|---|---|---|
| IS_FIRST(先攻/後攻) | 0% | **100%** |
| TO_ACTIVE(倒された後の補充) | 36% | **63%** |
| TO_HAND(サーチ先) | 41% | **53%** |
| MAIN(通常の行動選択) | 41% | **50%** |
| SWITCH(にげる先) | 86% | 85% |
| DISCARD(捨て札) | 12% | 14% |

MAIN の残り不一致はターン内の行動順の違い(cascade ノイズ)を多く含むため、
一致率100%を目指すべき指標ではない。DISCARD は次の改善対象。
