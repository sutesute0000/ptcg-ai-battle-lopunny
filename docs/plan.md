## 判明した事実

### 1. ローカル検証は採否の根拠に使えない

直近3件はローカルで +2.3 / +2.0 / +3.5 と出ながら、ラダーで −140 / −170 / −120。
**3打数0安打。** 相手ボットが実プレイヤーより大幅に弱いことが原因
(実測: Lucario戦はローカル73〜83%、実相性14%)。

→ **ローカルは「明らかな悪化を弾くフィルタ」に降格。採否はラダーのみ。**

### 2. 環境問題ではない

v9の実対局ログを確認: stderr空、フォールバックゼロ、最長判断0.4秒
(持ち時間600秒)。**正常動作した上で弱い。**

### 3. 成功と失敗を分けるもの

| 成功した2件 | 失敗した3件 |
|---|---|
| KO判定 = **厳密な事実** | 精度70.7%のモデルの**裁量を拡大** |
| ボスの指令 = **実在のバグ修正** | 調整済みスコアの**上書き範囲を拡大** |

**「事実」と「バグ修正」は効き、「判断の委譲」と「調整の変更」は効かない。**
弱い練習相手は判断ミスを許すが、実ラダーは許さない。
